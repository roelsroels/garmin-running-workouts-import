# Garmin Running Workouts Import 1.0.0

Version 1.0.0 is the first stable release of Garmin Running Workouts Import: a running-only planner that creates structured workouts, schedules them in Garmin Connect, and keeps the calendar understandable as the block progresses.

## Highlights

- Interactive CLI and web workflows for setting a goal, creating a reviewable training block, and importing approved workouts into Garmin Connect.
- FIT activity retrieval and local analysis to support supervised assessment and future-workout adaptations.
- Per-phase heart-rate caps, ranges, and Garmin zones, plus a one-off heart-rate workout builder.
- Preview-first scheduling, conflict inspection, and protected retirement of obsolete future workouts.
- Persistent Garmin request pacing and cooldowns to reduce avoidable rate-limit responses.
- A date-aware calendar that fades past/finished entries, identifies the next actionable run, and clearly labels today's scheduled workout.
- Portable local state and optional LLM explanations without requiring an LLM to plan workouts.

## Upgrade

From an existing checkout:

```shell
git fetch --tags
git checkout v1.0.0
uv sync --no-dev --locked
```

Existing data in `~/.garmin-running-workouts/` remains outside the Git checkout. Restart the web service after upgrading a server deployment.

## Install from the tag

```shell
git clone https://github.com/roelsroels/garmin-running-workouts-import.git
cd garmin-running-workouts-import
git checkout v1.0.0
uv sync --dev --locked
```

## Compatibility and scope

- Python 3.12 through 3.14.
- The project is intentionally running-only.
- Garmin Connect access uses private, unpublished endpoints and can require maintenance when Garmin changes them.
- Planning remains deterministic and evidence-informed, not medical advice or a clinically validated prescription.
