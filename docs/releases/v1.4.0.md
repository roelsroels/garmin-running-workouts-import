# Garmin Running Workouts Import 1.4.0

Version 1.4.0 brings system-aware light and dark themes to the web planner and clearer documentation of its
automatic Garmin Connect upload and scheduling workflow.

## Highlights

- **System / Light / Dark** controls at the top-right of every page. System is the default and follows your
  operating system or browser appearance, including changes while the page is open.
- **Remembered preferences:** a manual override persists in this browser across visits and synchronizes across
  open tabs. Selecting System clears the override. The preference is not stored in your Garmin account.
- **Complete light and dark palettes** cover forms, calendar statuses, completed and missed workouts, and the
  waiting screen. Finished runs remain visually subdued while keeping their text readable.
- **Responsive, accessible controls** support keyboard use and expose the selected mode to assistive technology.
  Icons keep the switch compact on narrow screens. Without JavaScript, colours still follow the system setting.
- **Clearer Garmin automation documentation:** the README includes an uploaded-workout screenshot and explains how
  an approved block becomes structured Garmin Connect workouts scheduled on the planned dates. Watch sync uses
  Garmin's normal device-transfer process; the optional .ics export is separate.

## Using the appearance switch

Choose **Light** or **Dark** at the top-right to override your system preference, or **System** to follow it again.
The saved choice is applied before the stylesheet loads to avoid briefly showing the wrong theme. If browser
storage is blocked, switching still works for the current page, but the override cannot persist across visits.

## Compatibility

- No new runtime dependencies, database migrations, or changes to workout planning or Garmin scheduling.
- Existing goals, plans, progress, FIT files, credentials, and scheduled workouts are retained.
- CLI commands remain unchanged. Python 3.12 through 3.14 are supported.
- Keep the web interface behind the documented authenticated TLS reverse proxy. The application remains
  single-runner; themes do not add multi-user accounts.

## Upgrade

For an existing deployment following `main`:

```shell
git switch main
git pull --ff-only origin main
uv sync --no-dev --locked
sudo systemctl restart garmin-running-workouts-web.service
```

Use your actual service name if it differs from the example. CLI-only installations do not need a service restart.
Preserve local changes before switching branches or pulling. Refresh the browser after updating; use a hard refresh
if it still shows the old appearance. No Garmin re-import or database copy is required.

To pin exactly this release instead:

```shell
git fetch origin --tags
git switch --detach v1.4.0
uv sync --no-dev --locked
```

Restart the web service after switching versions. A pinned checkout is detached; switch back to `main` before using
normal branch-based updates.

## Verification and downloads

Verified with the complete 212-test suite, including eight JavaScript preference tests, Ruff lint/format checks,
locked-dependency validation, and wheel/source-distribution builds. Browser checks cover light and dark rendering,
live system changes, manual overrides, reload persistence, cross-tab synchronization, mobile layouts, the waiting
screen, and the no-JavaScript fallback, using isolated dummy training data.

Downloads include a Python wheel, source distribution, and `SHA256SUMS`. GitHub also provides source archives of
the tag. CI checks Python 3.12, 3.13, and 3.14.
