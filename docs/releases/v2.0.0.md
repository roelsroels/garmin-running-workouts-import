# Garmin Running Workouts Import 2.0.0

Version 2 moves Garmin integration onto an explicit provider architecture. Completed activities and original FIT files
can come from Garmin's official Personal API, while approved Starter applications can publish and schedule structured
workouts through the official Training API. The authenticated Garmin Connect session remains available as a fallback.

## Highlights

- **Official activity ingestion:** use a Personal API key for running summaries and original FIT downloads without
  giving the planner an account password.
- **Official workout publishing:** connect an approved Starter application with OAuth 2.0/PKCE and publish, revise,
  schedule, and retire structured workouts through Garmin's Training API.
- **Independent providers:** choose the activity/FIT source separately from the workout/calendar publisher.
- **Web and CLI parity:** the interactive terminal now honors the selected publisher for plans and one-off workouts and
  exposes the same selective cleanup and provider settings as the web interface.
- **Scriptable administration:** new `providers` and `cleanup` command groups are JSON-producing and preview-first.
- **Resumable cleanup:** workout-template deletion checkpoints every item, reconciles templates already absent from
  Garmin, and resumes after network or Garmin failures.
- **Garmin-managed protection:** templates owned by Garmin adaptive training plans are identified, retained, and
  removed from the retry queue because Garmin forbids deleting them directly.

## New CLI commands

```shell
./garmin-workouts providers status
./garmin-workouts providers activity personal
./garmin-workouts providers starter-connect
./garmin-workouts providers training starter

./garmin-workouts cleanup workouts
./garmin-workouts cleanup workouts --apply --all --until-complete
./garmin-workouts cleanup workouts --resume --until-complete
./garmin-workouts cleanup schedules
./garmin-workouts cleanup schedules --apply --id 12345
./garmin-workouts cleanup overlaps
./garmin-workouts cleanup previous-block
```

Destructive commands remain previews until `--apply` is provided. Workout and schedule selections require either
repeatable `--id` options or `--all`.

## OAuth from the CLI

`providers starter-connect` creates a short-lived PKCE request and prints Garmin's authorization URL. Open it in a
browser while the configured planner web service is running. The registered HTTPS callback consumes the verifier from
the shared private data directory, completes the token exchange, and deletes the handoff. It expires after ten minutes
and never places the verifier or client secret in terminal arguments, SQLite, browser storage, or Git.

## Upgrade

```shell
git pull --ff-only origin main
uv sync --no-dev --locked
sudo systemctl restart garmin-running-workouts-web
```

There is no database migration requiring manual action. Existing legacy tokens, plans, activities, goals, and provider
defaults remain valid. The legacy workout publisher remains selected until the official Starter publisher is chosen
explicitly.
