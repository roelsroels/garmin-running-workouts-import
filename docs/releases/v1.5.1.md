# Garmin Running Workouts Import 1.5.1

Version 1.5.1 completes the finished-block rollover introduced in 1.5.0. After a replacement block has been uploaded
successfully, obsolete workout templates from the completed block are now removed from the Garmin Connect workout
library.

## Fixed

- **Finished workout-library cleanup:** applying the next training block removes templates that belonged only to the
  completed block, avoiding a growing list of old workouts in Garmin Connect.
- **Reused workouts remain available:** a workout template whose name is reused by the replacement block is protected
  from deletion.
- **Training evidence remains intact:** completed Garmin activities, downloaded FIT files, execution scores, recorded
  distances, and local planning history are not deleted.
- **Mid-block adaptations are unchanged:** this expanded cleanup is enabled only when the superseded block is finished.

The proposal review identifies when finished-block cleanup will occur, and the success message reports how many old
templates were removed.

## Upgrade

For an existing deployment following `main`:

```shell
git switch main
git pull --ff-only origin main
uv sync --no-dev --locked
sudo systemctl restart garmin-running-workouts-web.service
```

Use your actual service name if it differs from the supplied example. CLI-only installations do not need a service
restart.

To pin exactly this release instead:

```shell
git fetch origin --tags
git switch --detach v1.5.1
uv sync --no-dev --locked
```

Restart the web service after switching versions. A pinned checkout is detached; switch back to `main` before using
normal branch-based updates.

## Compatibility and verification

- No database migration and no new runtime dependencies.
- Existing goals, plans, progress, FIT files, credentials, completed activities, and scheduled history are retained.
- CLI commands and YAML formats remain compatible. Python 3.12 through 3.14 are supported.
- Verified with the complete 238-test Python suite, eight JavaScript theme tests, Ruff lint and formatting checks,
  locked-dependency validation, package builds, and an installed-wheel smoke test.

Downloads include a Python wheel, source distribution, and `SHA256SUMS`. GitHub also provides source archives of the
tag.
