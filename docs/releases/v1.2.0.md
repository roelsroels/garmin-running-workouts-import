# Garmin Running Workouts Import 1.2.0

Version 1.2.0 makes mid-block reassessment safer and easier to understand. Completed runs now inform the remaining
plan without becoming proposed calendar edits, while missed past workouts remain visible as history instead of being
silently moved.

## Highlights

- Completed workouts are immutable planning evidence and are never included in replacement proposals or Garmin
  calendar changes.
- Missed past workouts remain historical; they are not automatically caught up, moved, or rescheduled.
- Active-plan generation reassesses only upcoming mutable workouts instead of rebuilding the complete block.
- Proposal reviews show completed and missed history separately from the upcoming scheduled count, using the same
  status treatment as the calendar.
- Duration-based easy workouts round to the nearest five minutes, and normalized comparisons suppress rounding-only
  or otherwise equivalent changes.
- Demonstrated long-run distance informs progression without removing the intended reduced-load final week.
- Stale replacement proposals containing immutable dates are rejected before the application reads or changes the
  Garmin schedule.

## Upgrade

From an existing checkout:

```shell
git fetch --tags
git checkout v1.2.0
uv sync --no-dev --locked
```

Existing goals, plans, progress, downloaded FIT evidence, and Garmin tokens remain in
`~/.garmin-running-workouts/`. Version 1.2.0 does not require a database migration. Restart the web service after
upgrading a server deployment.

## Install from the tag

```shell
git clone https://github.com/roelsroels/garmin-running-workouts-import.git
cd garmin-running-workouts-import
git checkout v1.2.0
uv sync --dev --locked
```

## Compatibility and scope

- Python 3.12 through 3.14.
- The project is intentionally running-only.
- Garmin Connect access uses private, unpublished endpoints and can require maintenance when Garmin changes them.
- Planning remains deterministic and evidence-informed, not medical advice or a clinically validated prescription.
