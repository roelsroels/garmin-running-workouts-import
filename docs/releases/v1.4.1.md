# Garmin Running Workouts Import 1.4.1

Version 1.4.1 adds the actual distance run to completed-workout history and refreshes the documentation screenshots
to show the current light and dark interfaces.

## Highlights

- **Actual completed distance:** completed runs in the full calendar and proposal history show their Garmin-recorded
  distance in kilometres immediately beside the workout execution score.
- **Matching metric pills:** the distance and execution-score pills share the same score-band outline, text colour,
  shape, and spacing, and wrap safely on smaller screens.
- **Automatic database migration:** existing SQLite state gains an `actual_distance_m` field automatically. No manual
  database editing or data copy is required.
- **Current screenshot gallery:** the README now shows the latest dashboard, light and dark calendars with execution
  scores and distances, and the heart-rate workout builder in dark mode. All examples use synthetic data.

## Populating existing completed runs

Distance is stored from the Garmin activity matched during a progress refresh. After upgrading, use **Refresh
completed runs** once in the dashboard (or the equivalent CLI refresh command) to populate distances for workouts
that were already completed before v1.4.1. Future refreshes store the distance automatically.

If a completed activity has no usable distance in Garmin's summary, no distance pill is displayed. This does not
change the execution score or the completed status.

## Compatibility

- No new runtime dependencies and no changes to plan generation, Garmin workout uploads, or calendar scheduling.
- Existing goals, plans, progress, FIT files, credentials, and scheduled workouts are retained.
- CLI commands remain compatible. Python 3.12 through 3.14 are supported.
- The application remains a single-runner tool and should stay behind the documented authenticated TLS reverse proxy.

## Upgrade

For an existing deployment following `main`:

```shell
git switch main
git pull --ff-only origin main
uv sync --no-dev --locked
sudo systemctl restart garmin-running-workouts-web.service
```

Use your actual service name if it differs from the supplied example. CLI-only installations do not need a service
restart. Then refresh completed runs once to populate historical distances.

To pin exactly this release instead:

```shell
git fetch origin --tags
git switch --detach v1.4.1
uv sync --no-dev --locked
```

Restart the web service after switching versions. A pinned checkout is detached; switch back to `main` before using
normal branch-based updates.
