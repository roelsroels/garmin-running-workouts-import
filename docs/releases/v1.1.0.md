# Garmin Running Workouts Import 1.1.0

Version 1.1.0 improves the feedback loop between the active Garmin schedule and completed running activities. The calendar now explains elapsed dates more accurately and shows Garmin workout execution scores where those scores exist.

## Highlights

- Completed planned runs display Garmin workout execution scores in both the web and CLI calendars.
- If Garmin's activity summary omits a score, the refresh workflow downloads that activity's original FIT file once, reads the score, and caches the result locally.
- Execution scores use Garmin's documented visual bands: good 67–100%, average 34–66%, and low 0–33%.
- Completed workouts without a recorded score are explicitly labelled unavailable instead of being assigned a value.
- Elapsed scheduled dates without a matched running activity appear as missed; an unrefreshed date is labelled **Missed · needs refresh**.
- Today's scheduled workout remains clearly labelled and the first actionable workout remains highlighted as **Next**.
- README screenshots and the automation roadmap now reflect the current application.

## Upgrade

From an existing checkout:

```shell
git fetch --tags
git checkout v1.1.0
uv sync --no-dev --locked
```

Existing data in `~/.garmin-running-workouts/` remains outside the Git checkout. The SQLite schema adds execution-score columns automatically the first time version 1.1.0 opens the database. Existing goals, plans, downloaded FIT evidence, Garmin tokens, and completed activities are retained.

Restart the web service after upgrading a server deployment.

## Install from the tag

```shell
git clone https://github.com/roelsroels/garmin-running-workouts-import.git
cd garmin-running-workouts-import
git checkout v1.1.0
uv sync --dev --locked
```

## Execution-score scope

Garmin's workout execution score measures adherence to supported structured-workout targets. It is not a general fitness, effort, recovery, or health score. Garmin may omit it when a completed workout has no supported heart-rate, speed, pace, or power target.

Original FIT downloads used for score enrichment remain private in the local application data directory. A completed activity is checked only once unless its local state changes, limiting unnecessary Garmin requests.

## Compatibility and scope

- Python 3.12 through 3.14.
- The project is intentionally running-only.
- Garmin Connect access uses private, unpublished endpoints and can require maintenance when Garmin changes them.
- Planning remains deterministic and evidence-informed, not medical advice or a clinically validated prescription.
